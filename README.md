This is what happens when you combine a scientific modeling engine with a reasoning system that refuses to commit to the first plausible answer.  
  
Most AI tools give you one answer and move on. This one keeps multiple hypotheses alive, tests them against evidence, kills the weak ones, and only collapses to a conclusion when the data actually supports it.  
  
## The two pieces  
  
**Axiomize** handles the scientific modeling: explicit equations, dimensional analysis, sensitivity studies, reproducible exports.  
  
**Quantum Reasoning** handles the thinking: multi-branch exploration, evidence-based pruning, adaptive compute allocation. It's not quantum computing-it's just a metaphor for keeping possibilities open until you have real evidence.  
  
Together they let you build models where the reasoning process is as rigorous as the math.  
  
## Common use cases

- Explore several competing **mathematical models** before committing to one formulation.
- Combine **multi-branch AI reasoning** with parameter estimation, sensitivity analysis, and uncertainty quantification.
- Compare hypotheses using quantitative evidence instead of selecting the first plausible answer.
- Build reproducible scientific workflows that preserve both the **reasoning trace and mathematical model**.
- Apply quantum-inspired branch exploration to scientific modeling, model selection, planning, and decision support.

## Quick start  
  
```bash  
pip install axiomize-quantum-skills-2.0  
# or

```  
  
## Why I merged them  
  
I had the modeling engine and the reasoning skill as separate projects for a while. But every time I used one, I wanted the other. Building a model requires exploring multiple formulations. Reasoning about evidence requires quantitative checks. They belong together.
